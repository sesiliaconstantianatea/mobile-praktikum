# Dokumentasi Schema Database Supabase

## 1. Informasi Database

- Schema: `public`
- Nama tabel: `courses`
- Backend: Supabase PostgreSQL

## 2. Struktur Tabel `public.courses`

| Kolom | Tipe Data | Keterangan |
|---|---|---|
| `id` | `int8` | Primary key, identity/autogenerated |
| `code` | `text` | Kode mata kuliah |
| `title` | `text` | Nama mata kuliah |
| `credits` | `int4` | Jumlah SKS |
| `status` | `text` | Status mata kuliah |
| `created_at` | `timestamptz` | Waktu pembuatan data, default `now()` |

## 4. Konfigurasi Data API

- Enable Data API: ON
- Exposed schemas: `graphql_public` dan `public`
- Tabel terekspos: `public.courses`
- Status paparan tabel: 1 of 1 tables exposed

## 5. Izin dan Row Level Security (RLS)

- RLS: Aktif
- Hak akses SELECT: diberikan kepada role `anon` dan `authenticated`
- Policy: `courses_select_policy`
- Policy command: SELECT
- Policy behavior: PERMISSIVE
- Target roles: `anon` dan `authenticated`
- Kondisi USING: `true`

Policy ini mengizinkan pembacaan baris oleh role yang ditentukan, dengan tetap tunduk pada hak akses tabel dan konfigurasi RLS.
