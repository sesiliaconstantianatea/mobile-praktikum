# Proyek Pemrograman Mobile

## Deskripsi
Aplikasi Flutter latihan untuk pembelajaran pemrograman berbasis mobile.

## Tujuan

Aplikasi ini dibuat sebagai proyek pembelajaran Flutter untuk memahami dasar-dasar pengembangan aplikasi mobile.

## Rencana Fitur

1. Tampilan halaman utama aplikasi.
2. Navigasi antarhalaman.
3. Menampilkan dan mengelola data sederhana.

## Cara Menjalankan

1. Pastikan Flutter sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan perintah:

```markdown
```bash
flutter pub get
flutter run
